# Placement Portal

A web-based Placement Portal developed as a BCA project to help students explore job opportunities and manage job applications.

## Features

- Student Registration and Login
- Student Dashboard
- Student Profile Management
- Job Listings
- Job Application Management
- Admin Dashboard
- MongoDB Database Integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

```text
placementportal/

```

## Backend Setup

1. Install Node.js.
2. Open the backend folder in the terminal.
3. Run:

```bash
npm install
```

4. Create a `.env` file and configure your MongoDB connection.
5. Start the backend:

```bash
node server.js
```
